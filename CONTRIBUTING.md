# Contributing to Nudge

Thanks for wanting to help!

## Report a bug

[Open an issue](https://github.com/IvanHlazkov/Nudge/issues/new/choose) using the **Bug report** template. Include your macOS version, your Nudge version (Settings, bottom left) and the steps to make it happen.

## Suggest an idea

[Open an issue](https://github.com/IvanHlazkov/Nudge/issues/new/choose) using the **Feature request** template. Say what you want to do and why.

## Send code

Nudge is **not open source** (see [LICENSE](LICENSE)), but pull requests for bug fixes are welcome.

1. Open an issue first for anything bigger than a small fix, so we can agree on it before you spend time on it.
2. Fork the repo and make your change on a new branch.
3. Build and test it in Xcode 16 or newer (see "Build it yourself" in the [README](README.md)).
4. Open a pull request and fill in the template.

By sending a pull request, you agree that your contribution can be used in Nudge under the same terms as the rest of the project, and that Ivan Hlazkov (Glaz Labs) keeps the copyright to Nudge.

## Security problems

Please don't report them in public issues. See [SECURITY.md](SECURITY.md).

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
