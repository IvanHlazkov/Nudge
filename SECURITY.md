# Security Policy

## Supported versions

Only the [latest release](https://github.com/IvanHlazkov/Nudge/releases/latest) of Nudge gets security fixes.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report it privately instead: go to the [Security tab](https://github.com/IvanHlazkov/Nudge/security) and click **Report a vulnerability**. Only the maintainer can see it.

Please include:

- What the problem is and what someone could do with it
- Steps to reproduce it
- Your macOS version and Nudge version

You'll get a reply as soon as possible. Once it's fixed, a new release will be published and you'll be credited if you want.
